Screenshot a Browser tab, draw on it, and hand it to your agent.

## What you get

- A camera button in the desktop Browser toolbar, next to Agent Annotations.
- An editor with a pen, highlighter, arrows, rectangles, ellipses, text, seven colors and undo/redo.
- Copy image, to paste the PNG into any composer as a normal attachment.
- Add to prompt, which drops an `@Screenshot` mention the agent receives as an image.

## How it works

The capture comes from the desktop app's own tab capture, so it never takes control of the page. Images added to the prompt are stored as project attachments, the same way pasted images are, so they reach the thread's machine without extra setup.
